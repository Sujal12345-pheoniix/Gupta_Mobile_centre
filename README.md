# Gupta Mobile Centre

Production-oriented retail management platform for mobile accessories and parts.

## Core capabilities
POS, inventory, purchases, suppliers, customers, quotations, returns, finance, employees, payroll, reporting, approvals and audit.

## Architecture
Modular monolith + PostgreSQL, with Next.js admin and Flutter mobile clients.

## Getting started
Read:
1. `CLAUDE.md`
2. `docs/PRD.md`
3. `docs/IMPLEMENTATION_ROADMAP.md`
4. `docs/CLAUDE_FIRST_PROMPT.md`

Do not start by generating the entire application. Start with Phase 0 and the first vertical slice.
